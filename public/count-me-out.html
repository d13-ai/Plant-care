This browser isn't counted

For the people building PlantParlour

Visits from this browser are no longer counted in PlantParlour's page-view numbers, so the figures show real visitors rather than our own testing. It applies to this browser on this device only — open this page once on each phone and computer you use.

Visits already counted stay in the figures; this only affects visits from now on.

Count this browser again

On an iPhone, a PlantParlour added to the home screen keeps its own storage apart from Safari, so it needs opting out separately — which it can't be from here yet.
